# BCA Semester III study pack

English notes and solved practical workbooks for Web Designing, RDBMS Using
MySQL, Operating Systems, Linux Server Administration, and Linux & Shell
Programming. The package includes 58 official practical solutions, eight
supplementary OS exercises, source-code archives and a local study portal.

The five combined subject PDFs total 127 pages. The full uploaded syllabus is
not redistributed. Personal student details are blank templates.

Run `py setup_college_portal.py` on Windows with Python 3.10 or newer. Initial
setup needs Internet access to retrieve and verify the package; the installed
portal and PDFs work locally. VS Code is optional for viewing/editing source.

The installer creates a new Desktop folder and preserves existing folders.
See the package README for the detailed verification results and limitations.

The installer retrieves an immutable Git revision and verifies the package's
SHA-256 checksum before extracting it. This project is published on the
`college-study-portal` branch.
